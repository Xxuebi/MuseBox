# MuseBox

MuseBox（中文副标题：灵感收集器）是面向 Windows 10/11 的轻量本地图片收集与自由画板工具。主窗口可置顶和拉伸，每个抽屉对应独立的无限画板；默认 A–D，可继续新增更多抽屉。

- “透明度影响图片”文字与开关改为同一水平行并垂直居中，不再上下脱离。
- 右键菜单关闭时不再创建额外的淡出快照窗口，消除原生菜单消失后短暂重现的闪烁。

## 使用

1. 启动 MuseBox.exe。每张抽屉卡片上方为收集/预览区域，下方左侧显示字母、右侧显示名称，点击打开画板；按钮内右侧的“三横杠＋下三角”展开抽屉菜单。底部“新建抽屉”依次添加 E、F…Z、AA…，不再限制四个。
2. 使用以下任一方式导入：
   - 截图或复制图片后，点击目标抽屉上方的收集区；
   - 把 PNG、JPEG、BMP、GIF 或 TIFF 文件拖到目标抽屉的收集区；
   - 点击标题下方“截图”或按默认全局快捷键 Ctrl+Shift+A 框选区域，再点击目标抽屉的收集区；
   - 在已打开的画板中按 Ctrl+V，或直接把图片文件拖到画板。
3. 普通模式下，点击卡片下方的字母和名称区域打开对应画板；沉浸模式下则用于收集。全局设置的“常规”页可以关闭字母标识；编号和画板内容不受影响。再次收集图片时，上一张预览向下缩小并淡出。
4. 拖动小窗四边或四角可拉伸，抽屉自动按宽度换列，更多抽屉向下滚动。新建按钮固定在底部，新抽屉创建后滚动到列表末尾；重新启动会恢复小窗尺寸。
5. 单击抽屉按钮内的菜单图标，展开圆角菜单以重命名或删除，不会同时打开画板。A–D 是保留入口，A 不可删除，B–D 为“清空并重置”；新增的 E 等抽屉提供“删除抽屉”。清空和删除都需确认，不影响其他抽屉。
6. 长按菜单图标约 0.42 秒，进入抽屉排序；浮起的卡片保持抓取位置并跟随鼠标，相邻卡片平滑让位，松开后以回落动画放入新位置并保存。按 Esc 取消并返回原位置。拖到列表上下边缘会自动滚动，重新启动后保留顺序，抽屉编号和内容保持不变。

框选时收集器会自动隐藏，完成后截图进入剪贴板并恢复小窗。关闭收集器窗口会收进系统托盘；托盘菜单可以显示主窗、按当前抽屉顺序打开画板或彻底退出。应用内悬停提示、抽屉菜单和托盘右键菜单采用统一的圆角、轻阴影样式。

“常规”页新增“使用系统自带截图”（默认关闭）。开启后，“截图”按钮和截图快捷键调用 Windows 的截图工具，不会在启动应用时自动截图；截图完成或取消后恢复小窗。此入口使用 [Windows 的 Win+Shift+S 截图快捷方式](https://support.microsoft.com/en-us/windows/apps/use-snipping-tool-to-capture-screenshots)，无需更改注册表或安装协议处理程序。系统截图工具的自动保存和剪贴板选项由 Windows 自身控制；关闭此开关则使用收集器原有的框选截图。

## 画板操作

- 鼠标滚轮：以指针位置为中心缩放
- 鼠标中键或 Space + 左键：平移画布；按住空白区域右键可移动画板窗口，轻点右键仍显示菜单
- 左键拖动：移动图片、注释或绘制元素；选中后通过贴边的八个控制点缩放，四角外侧控制点旋转。图片和绘制默认等比例，按 Shift 自由拉伸，按 Alt 从中心缩放
- 旋转后的单张图片（含 GIF）沿自身的横纵轴拉伸，按 Shift 拖动边中点时只改变对应方向的尺寸，对侧锚点保持不动；Alt 保持中心不动。角点、等比例缩放、不同画板缩放倍率以及撤回/重做沿用同一套旋转坐标计算。
- 选择框使用细线和圆角手柄，保留较大的透明拖动区域；四角外侧显示弧形双箭头旋转光标，与贴边的拉伸区域分开
- 旋转控制点靠近图片，光标使用清晰的双箭头；按住 Shift 时吸附到 5° 的倍数。双击单张图片会将视角居中并适配当前窗口，不更改图片本身尺寸或切换系统全屏
- 选择两张以上图片后右键“打组”，单击组内图片会选中整个组，支持整体移动、缩放、旋转、删除；右键“解组”保持成员位置不变。组关系保存到数据库，支持撤回和重做
- 自动排列只处理选中图片；无选择时排列全部图片。图片组作为一个整体参与排列，不改变组内相对位置，也不移动未选中的图片
- Ctrl：追加选择；空白处拖框：框选；Ctrl+A：全选
- T：添加富文本注释；B：画笔；E：橡皮擦；V 或 Esc：返回选择。绘制工具栏只保留一种画笔，直线、箭头、矩形和椭圆收纳在形状菜单中；粗细、透明度及虚实线收纳在线条菜单中，颜色按钮下方实时显示色条
- 一次进入绘制到退出绘制之间的笔画和形状保存为一个整体，可整体选择、移动、缩放、旋转、分层或删除。返回选择模式后双击已有笔迹可续画到同一组；重新进入绘制则建立新组，即使笔画重叠也不会自动合并
- 每一笔分别保存颜色、粗细和透明度，调整工具设置只影响之后的笔画；每笔可单独撤回，橡皮擦可切开组内自由笔迹或删除命中的组内形状。窗口关闭前会保存未完成的最后一笔，旧版单笔数据继续兼容
- 绘制过程中及完成后不自动显示笔迹边框，单击选择或双击续画时才显示；开始续画后边框再次隐藏。橡皮擦右侧的小三角可独立调整直径（8–160 px），画板内用圆圈显示范围，大小不受画笔粗细影响
- 文字工具栏贴近所选注释显示；重复选择、缩放、旋转和调整窗口大小时保持稳定定位，空间不足时自动换到注释下方并限制在窗口内
- 绘制与文字工具栏的小菜单均为点击打开、再次点击关闭，点击菜单外部也会关闭；菜单与工具栏之间留出间距，尖角完整显示，文字更多菜单靠近底边时可向上展开
- 文字和绘制菜单的尖角对齐打开按钮中心；清除格式使用“文字＋橡皮擦”图标
- 文字右侧更多菜单提供“清除文字样式”“复制文字样式”“粘贴文字样式”；样式包括字体、字号、粗体、斜体、下划线、颜色、对齐和注释背景，不复制文字内容，也不覆盖系统剪贴板。编辑时应用到选择文字，未编辑时应用到整条注释
- 橡皮擦拖动时逐帧实时擦除，输入点按帧合并；松手后才统一保存，并只产生一次撤回记录。关闭绘制或窗口时也会提交最后尚未渲染的擦除输入
- 顶部最小化和关闭按钮之间新增全屏按钮，F11 可切换全屏；进入后覆盖当前显示器，退出后恢复原窗口位置和大小，不改变置顶设置。选择模式下 Esc 也可退出全屏
- Delete：删除；Ctrl+C/V：复制/粘贴图片；Ctrl+Z/Y：撤销/重做
- 右键菜单同时提供“撤回”和“重做”，每次重做一步；新操作会清除旧重做分支。全局设置的“常规”页可设置每个画板保留的撤回步数（1–500，默认 100），修改即时生效
- 顶部控制栏默认展开；点击下方三角收起或展开，鼠标经过和 Alt 不再触发显隐
- 画板右键菜单：添加注释、绘制、撤回、粘贴、适应、排布、层级、删除和设置；菜单右侧显示当前快捷键
- 主设置窗口的“键盘快捷键”页使用紧凑分组和圆角按键框，可按功能名称、分组或组合键搜索；筛选后编辑仍保留所有快捷键并进行完整冲突检查

图片和 SQLite 数据库默认保存在 %LocalAppData%\MuseBox；旧版 %LocalAppData%\InspirationCollector 资料会在首次启动时兼容迁移。导入的图片会复制到资料库并按 SHA-256 去重，之后不依赖原文件。应用完全离线，不上传图片。

## 图片工具与编辑器

- 单击图片上方的铅笔，以展开动画打开图片工具条并聚焦当前图片；静态图片工具条提供编辑、水平/垂直翻转、顺时针旋转 90° 和网页/文件链接。裁切与调色保留在编辑器内，不再重复放在工具条。
- 编辑器使用统一图标，支持正反向旋转 90°。拖出裁切区域后，在选框右下角点击勾号确认或叉号取消。
- 色相、饱和度、亮度、对比度使用渐变滑条，数字可手动输入。预览复用缩略图和像素缓冲，连续刷新；应用和另存使用原始分辨率。
- Ctrl+Z 或撤回图标可撤回调色、裁切、翻转、旋转、重置；一次滑块拖动计为一步，编辑器最多保留 50 步，并限制像素历史的内存占用。
- “应用”更新画板中的当前图片；“另存”在画板新增图片，保留原图片。两者均可在画板撤回，均不覆盖原始图片资源。
- 画笔粗细、透明度及橡皮擦直径的单位贴近数字，点击时选中数字，输入框临时展开覆盖单位。
- 编辑器中点击数字输入框以外的位置会提交数值并收起输入边框，当前点击仍正常生效；链接输入框右侧可以一键清空，点击保存后移除对应链接。

## 注释链接

- 单击注释，在文字工具栏右侧的子菜单里点击链接图标，可分别设置网页地址和自定义文件/文件夹地址；输入框右侧可清空对应链接。
- 选中注释时，已设置的链接显示为文字右下角外侧的小按钮，只配置一个地址时只显示对应按钮。按钮跟随缩放、旋转、移动和窗口尺寸；靠近底边时自动改到外侧，避免覆盖文字和控制点。
- 链接跟随注释保存并支持画板撤回/重做；设置链接前会先提交文字编辑，文字与链接分别计入历史。旧注释数据库自动补充空链接，不改变原文字和样式。

## GIF 动图

- 拖入 GIF 文件，或在资源管理器复制 GIF 文件后收集到小窗/粘贴到画板，都会保留原始动画。1.0.26 也保留剪贴板 GIF/image-gif/FileContents 等格式和网页内嵌 GIF 数据，优先使用原始编码而非同时提供的 PNG/位图预览。
- 动图识别使用文件头，不依赖后缀；新导入按实际格式命名，旧资源若只是后缀错误也可直接播放。已被转换成真正静态 PNG 的旧图片不含其他帧，需要用原始 GIF 重新收集。
- 网页复制若提供 HTTP(S) GIF 原图地址，点击收集时会读取该地址（15 秒超时、128 MiB 上限），不会在剪贴板状态检查时联网。读取失败或响应不是 GIF 时提示保存原 GIF 文件后拖入，不会悄悄替换成静态预览。若剪贴板既无 GIF 原始数据也无 GIF 原图地址，无法从静态像素恢复动画。
- GIF 上方使用叠帧播放图标，与普通图片的铅笔区分。独立工具条提供上一帧、播放/暂停切换、下一帧、0.25×–4× 倍速、全部帧和链接。播放与暂停共用同一按钮，图标与提示随状态更新；逐帧切换会暂停，首尾帧可以循环切换；重新打开画板默认从首帧播放。
- “全部帧”打开帧面板并暂停，每张缩略帧右下角标注帧号。单击任意帧，主图跳转并暂停在该帧。
- 暂停时右键主图，选择“另存当前帧为新图片”，会新增原分辨率 PNG，保留原 GIF，并支持画板撤回/重做。
- GIF 按各帧时长循环播放，处理透明区域、局部帧与恢复背景/前帧的处置模式。后台解码，预览缓存按单个动图 64 MiB 和最长边 1000 px 控制；帧导出重新以原尺寸合成。不支持超过 5000 帧或 4000 万画布像素的文件，会显示错误提示。
- GIF 元数据使用 [Microsoft WIC 元数据接口](https://learn.microsoft.com/en-us/windows/win32/wic/-wic-native-image-format-metadata-queries)，合成顺序参考 [Microsoft 动图示例说明](https://github.com/microsoft/Windows-classic-samples/blob/main/Samples/Win7Samples/multimedia/wic/wicanimatedgif/WicAnimatedGif.cpp)。

## 构建与测试

需要 .NET 8 SDK：

    dotnet build .\MuseBox.sln -c Release
    dotnet run --project .\MuseBox.Tests\MuseBox.Tests.csproj -c Release

测试覆盖多显示器截图坐标、缩放数学、500 项排布、SQLite 恢复、图片去重和窗口构造，以及抽屉排序保存/取消/失败回滚、内嵌菜单和跟手/让位动画、字母显示设置、圆角菜单与提示框、旋转图片八向拉伸与固定锚点、拉伸持久化及撤回/重做、系统截图按键和完成/取消状态。系统截图测试不发送实际快捷键，也不改动用户剪贴板。

## 发布与安装包

生成 Windows x64 自包含版本：

    dotnet publish .\MuseBox.csproj -p:PublishProfile=win-x64

输出位于 publish\v<版本号>（当前为 publish\v1.1.15），保留旧版本目录。默认不构建安装包；用户明确要求后，才使用 Inno Setup 6 编译 Installer\InspirationCollector.iss。安装任务默认勾选关联 .mubo；便携版不会自行更改注册表。更新前先从托盘退出旧版；默认数据目录为 %LocalAppData%\MuseBox，旧 %LocalAppData%\InspirationCollector 仅用于首次兼容迁移。

本机构建采用 Inno Setup 6.7.3。安装器使用内置图标以避免此环境更新启动器图标时的 Windows 错误 110；安装后的程序、托盘及场景文件仍使用应用图标。

每轮用户可见修改交付时递增补丁版本号；同一轮的编译、测试和打包重试不重复递增。项目 Version、AssemblyVersion、FileVersion 与安装包 MyAppVersion 保持一致。发布目录只使用简短版本号，不追加功能描述后缀；保留旧版本目录，不覆盖正在运行的程序。

应用图标和场景文件图标的源文件分别为 Assets/app-icon.png 与 Assets/scene-icon.svg，使用 tools/build-icon.cjs（需要 sharp）生成多尺寸 ICO 和 PNG 预览；窗口、托盘、EXE 和关于页使用 Assets/app-icon.ico，未来安装版的 .mubo 文件关联使用随发布目录提供的 Assets/scene-icon.ico。沉浸收集按钮使用 Assets/immersive-collection-icon.png。
